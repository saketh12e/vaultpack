A heap-buffer-overflow write occurs in `vp_decompress_lz4x()` in `src/decompress_lz4.c` when a chained block input has multiple consecutive LZ4X sub-blocks whose per-block declared decoded sizes each pass the per-block size check but whose running sum exceeds the caller's output buffer capacity. The decoder accumulates per-block totals in a local size and never compares the cumulative sum against the destination buffer length before writing the next block's literal bytes. The downstream memcpy writes past the allocation.
