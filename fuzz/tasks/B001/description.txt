A heap buffer overflow occurs in `vp_aggregate_metadata()` in `src/archive.c` when accumulated `meta_count` values across directory entries wrap a `uint32_t` sum. Three entries each with `meta_count = 0x55555556` sum to `0x100000002`, which wraps to `2` in `uint32_t`. `calloc(2, sizeof(vp_meta_entry_t))` allocates only 128 bytes, but the subsequent fill loop writes the unwrapped count of entries past the end of that allocation via `memcpy`, corrupting the heap.
