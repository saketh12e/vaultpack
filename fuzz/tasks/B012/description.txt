A heap-use-after-free read occurs in `vp_section_pipeline_run()` in `src/section_pipeline.c` after an error path invalidates the inflated scratch buffer. The pipeline allocates an internal scratch buffer for the decoder output, copies it into the caller-visible `*out` on success, and clears its internal reference. On decoder failure the internal reference is left non-NULL and a subsequent error-recovery path returns to a stale scratch view held by a freed internal slot, producing a read through the old pointer when the caller queries the pipeline status.
