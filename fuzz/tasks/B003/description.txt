A global buffer over-read occurs in `vp_process_meta_block()` in `src/metadata.c` when the dispatch table index is computed as the sum of two masked tag bytes. Each byte is masked to six bits, so each value is bounded 0–63, but their sum ranges 0–126 and can exceed the 64-entry static `vp_meta_dispatch` table. A tag with first byte `0xFF` and second byte `0x42` produces index 65, which reads past the end of the table.
