A double-free occurs in `vp_extract_cleanup()` in `src/extract.c` when truncated section data causes `vp_extract_section()` to free the output buffer through `vp_section_cleanup()` without clearing the pointer alias in the extraction context. The cleanup routine then frees the same buffer a second time. The alias is created by `sec.data = ctx->out_buf` and the bug surfaces whenever `vp_fill_section_data()` returns a truncation error before cleanup runs.
